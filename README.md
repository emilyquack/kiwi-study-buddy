# Kiwi Study Buddy

Kiwi Study Buddy is a cozy pastel study website organized by broad school subjects:

- General Biology
- General Chemistry
- General Physics
- Math from Algebra 1 through Calculus 3
- Psychology
- English / Writing
- History

The first version is intentionally local-first and lightweight. It saves the selected subject, math level, saved topics, and weak spots in browser localStorage.

## Run locally

```bash
npm test
npm run serve
```

Then open http://localhost:5173.

## Current v1 features

- Subject-first study mode cards
- Math pathway selector
- Study actions: explain, quiz, flashcards, practice, study guide, and subject-specific tools
- Confidence tracker with weak-topic sticky notes
- Floating Kiwi companion widget
- Pastel academic cat café aesthetic
- Responsive layout for desktop and mobile
